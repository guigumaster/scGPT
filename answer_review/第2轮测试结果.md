# 第2轮测试结果评审报告

## 结论：不合格

---

## 一、概述

本轮优化采用 **PCT-AIM v2（Perturbation-Conditioned Cross-Modal Transformer with Adaptive Importance Masking）** 方案，在 scGPT 的 Transformer 架构基础上引入三个机制：(1) 扰动条件编码器，(2) 跨模态交叉注意力层，(3) 任务自适应重要性掩码策略。本轮相比第1轮进行了多项配置调整（更大的batch_size=64、更多的Transformer层数nlayers=12、更合适的学习率、启用预训练权重等），旨在统一优化三个核心任务：扰动预测、多批次整合、大规模扰动预测。

## 二、基线模型性能指标（baseline.md）

基线模型为 scGPT Multiomic Integration，在 **BMMC（Bone Marrow Mononuclear Cells，CITE-seq RNA+Protein）** 数据集上运行，评估指标如下：

| 指标类别 | 指标 | 基线值 |
|---------|------|--------|
| 生物保守性 | NMI (cluster/label) | **0.6668** |
| 生物保守性 | ARI (cluster/label) | **0.7100** |
| 生物保守性 | ASW (label) | **0.6635** |
| 批次校正 | ASW (batch) | 0.8246 |
| 批次校正 | PCR (batch) | 0.3289 |
| 批次校正 | graph connectivity | 0.8734 |

## 三、PCT-AIM v2 优化后测试结果

### 任务1：扰动预测（Norman 2019 数据集）

训练过程（20 epochs）：验证损失从 124.04 降至 62.76，扰动损失（pert_loss）从 0.70 降至 0.09。

| 指标 | 测试值 | 与基线对比 |
|------|--------|-----------|
| NMI (cluster/label) | **0.0765** | ❌ 大幅下降（0.6668 → 0.0765） |
| ARI (cluster/label) | **0.0243** | ❌ 大幅下降（0.7100 → 0.0243） |
| ASW (label) | **0.4409** | ❌ 下降（0.6635 → 0.4409） |
| ASW (batch) | **0.9383** | ✅ 提升（0.8246 → 0.9383） |
| PCR (batch) | **0.4267** | ✅ 提升（0.3289 → 0.4267） |
| graph connectivity | **0.8387** | ❌ 下降（0.8734 → 0.8387） |

### 任务2：多批次整合（PBMC 10K 数据集）

训练过程（20 epochs）：验证损失从 81.21 降至 43.04。

| 指标 | 测试值 | 与基线对比 |
|------|--------|-----------|
| NMI (cluster/label) | **0.7108** | ✅ 提升（0.6668 → 0.7108） |
| ARI (cluster/label) | **0.5848** | ❌ 显著下降（0.7100 → 0.5848） |
| ASW (label) | **0.6838** | ✅ 略升（0.6635 → 0.6838） |
| ASW (batch) | **0.9267** | ✅ 提升（0.8246 → 0.9267） |
| PCR (batch) | **0.0000** | ❌ **严重倒退**（0.3289 → 0.0000） |
| graph connectivity | **0.9319** | ✅ 提升（0.8734 → 0.9319） |

> ⚠️ PCR_batch=0.0000 的原因：日志显示 *"Variance contribution increased after integration! Setting PCR comparison score to 0."* 说明批次校正后主成分的方差贡献反而增大，表明整合效果劣于不整合。

### 任务3：大规模扰动预测（Replogle 2022 数据集）

训练过程（15 epochs）：验证损失从 30.73 降至 30.17（最佳模型在第8轮 epoch 8，val_loss=30.1729）。由于 Replogle 数据集为小鼠数据（仅 6/13201 基因匹配人源预训练词汇表），模型从随机初始化训练，性能受限。未报告 scIB 评估指标，无法与基线直接比较。

## 五、关键问题分析

### 5.1 生物保守性指标部分提升，ARI 仍低于基线

- **NMI** 从基线 0.6668 提升至 **0.7108**（+6.6%）✅
- **ASW_label** 从基线 0.6635 提升至 **0.6838**（+3.1%）✅
- **ARI** 从基线 0.7100 降至 **0.5848**（-17.6%）❌

ARI 是衡量细胞聚类一致性的核心指标，本轮 ARI=0.5848 远低于基线 0.7100，表明细胞类型聚类的一致性仍然不足。

### 5.2 批次校正指标出现严重倒退

- **PCR_batch** 从基线 0.3289 降至 **0.0000**（完全失效）❌❌
- 日志明确表明整合后主成分方差贡献反而增加，DAB（Domain Adversarial Regularization）未能有效消除批次效应
- 尽管 **ASW_batch**（0.9267）和 **graph connectivity**（0.9319）有所提升，但 PCR_batch 的完全失效是致命问题

### 5.3 跨模态交叉注意力仍然未启用

运行脚本显示任务2（Integration）中 `use_cross_modal=False`，表明旨在实现 RNA 与 Protein 模态间显式对齐的跨模态交叉注意力层在本轮测试中仍然未启用。这是 PCT-AIM 方案的核心机制之一，缺失该机制使得本轮优化方案与原始 scGPT 的集成方法无本质区别。

### 5.4 扰动条件编码器在扰动预测任务中效果有限

在任务1（Norman 数据集）中，虽然 `use_pert_cond=True` 启用了扰动条件编码器，且训练过程中 pert_loss 从 0.70 降至 0.09、MSE 从 124.04 降至 62.76，但下游评估指标（NMI=0.0765, ARI=0.0243）极低，说明模型虽然拟合了训练数据，但生成的细胞表示未能有效区分不同扰动条件下的细胞状态。

### 5.5 不同数据集限制了可比性

基线使用 BMMC 数据集（RNA+Protein，12578细胞，3个批次），而本轮测试使用不同的数据集（Norman/PBMC 10K/Replogle），无法在完全相同的条件下进行公平对比。

## 六、综合判定

| 评判维度 | 结果 |
|---------|------|
| 核心生物保守性指标（ARI）是否超过基线 | ❌ 否（0.5848 < 0.7100） |
| 批次校正指标是否整体超过基线 | ❌ 否（PCR_batch=0.0000 完全失效） |
| 整体超过基线（所有核心指标均优于基线） | ❌ 否 |
| 相比第1轮是否有所提升 | ✅ 是（NMI/ARI/ASW_label 大幅提升） |

**判定结论：不合格**

虽然本轮相比第1轮在 NMI、ARI、ASW_label 等指标上取得了显著进步（修复了嵌入维度、预训练权重、层数等问题），但 **ARI（0.5848）** 和 **PCR_batch（0.0000）** 两个核心指标均未达到基线水平。特别是 PCR_batch=0.0000 表明批次校正完全失效，这是一个严重的倒退。

**改进建议：**
1. **启用跨模态交叉注意力**（设置 `use_cross_modal=True`），实现 RNA-Protein 模态间显式对齐，这是 PCT-AIM 方案的核心创新之一
2. **调试 DAB 模块**，修复批次校正失效问题（PCR_batch=0.0000），可尝试调整 dab_weight、增加判别器容量或调整训练策略
3. **使用与基线相同的数据集**（BMMC CITE-seq）进行公平对比，消除数据集差异带来的影响
4. **进一步优化扰动条件编码器**，提升扰动任务中细胞表示的判别力（NMI/ARI 极低）
5. **调整批次校正与表达预测之间的平衡**，避免 DAB 过度破坏生物信号
