### 1. `tutorials/Tutorial_Integration.py` — 主要修改

| 修改项 | 原代码 | 修改后 | 说明 |
|--------|--------|--------|------|
| **`prepare_data` 函数** | `def prepare_data(sort_seq_batch=False)` → 内部引用未定义 `epoch` | `def prepare_data(sort_seq_batch=False, epoch=1)` | 修复 NameError bug |
| **`data_is_raw` 标志** | 本地数据加载时 `data_is_raw = True` | `data_is_raw = False` | 避免双 log1p 变换 |
| **模型容量（从头训练）** | `embsize=128, nhead=4, nlayers=4` | `embsize=256, nhead=8, nlayers=6` | 提升模型表达能力 |
| **训练轮数** | 15 epochs（固定） | 60 epochs（从头训练）/ 25 epochs（有预训练） | 确保模型充分收敛 |
| **学习率调度** | `StepLR(optimizer, 1, gamma=0.9)` | `CosineAnnealingLR(optimizer, T_max=epochs, eta_min=1e-6)` | 平滑衰减学习率 |
| **优化器** | `Adam` | `AdamW` (weight_decay=0.01) | 更好的正则化 |
| **梯度累积** | 无 | `gradient_accumulation_steps=4`（从头训练） | 稳定训练，等效大 batch |
| **标记基因检测** | 使用**分箱后**的训练数据重新归一化 | 使用**全量数据**的 `X_log1p` 层 | 更准确的标记基因发现 |

| **最佳模型追踪** | 仅追踪最低 val_loss | 同时追踪最低 val_loss 和最高 avg_bio | 确保保留最佳聚类模型 |
| **最终评估** | 无 | 训练结束后运行完整 scIB 评估，保存 `final_metrics.json` | 便于结果对比 |

### 3. 关键修复说明

**Bug #1（致命）**：`prepare_data()` 函数在 `print` 语句中引用了 `epoch` 变量，但该变量只在训练循环的 `for epoch in range(1, config.epochs + 1)` 中定义。虽然 Python 会从闭包中查找，但这是不规范的写法，已添加显式参数。

**Bug #2（重要）**：本地 `pbmc10k_scgpt_ready.h5ad` 数据已经过 log1p 归一化，但 `data_is_raw = True` 导致预处理管线再次执行 log1p，造成双 log1p 变换，破坏数据分布。

**Bug #3（重要）**：标记基因检测使用分箱后的离散数据（0-50 整数），对其再次 `normalize_total` + `log1p` 毫无意义。已改为使用 `adata.layers["X_log1p"]` 的连续值进行差异表达分析。
