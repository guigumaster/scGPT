### 5 Improvement Implementations

**1. Cosine Annealing DAR Curriculum**
- DAB weight follows 3-phase cosine schedule: Phase 1 (0-30% epochs, low=0.1) → Phase 2 (30-70%, cosine ramp to max=1.0) → Phase 3 (70-100%, slight decay)
- Gradient reversal coefficient follows similar schedule with different phase boundaries
- Both are computed per-epoch via `get_cosine_dab_weight()` and `get_cosine_grad_reverse_lambda()` in `trainer.py`
- Applied to discriminator via `model.grad_reverse_discriminator.set_lambda()` (both `model.py` and `multiomic_model.py`)

**2. Elastic Cell Similarity (ECS) Regularization**
- Enabled with `ecs_thres=0.8` (configurable)
- Adaptive threshold `ecs_threshold_adaptive` used in both model variants
- Loss weight: `10 * loss_ecs` per the baseline

**3. 8-layer Transformer Encoder**
- `nlayers=8` (up from 4), `pre_norm=True` for training stability
- Same `d_model=128`, `nhead=4` as baseline

**4. Dynamic Mask Ratio Curriculum**
- Linearly increases from `0.25` → `0.55` over `mask_ratio_warmup_epochs=15`
- Computed by `get_curriculum_mask_ratio()` in `trainer.py`

**5. Warmup Cosine LR Schedule**
- Linear warmup for 3 epochs, then cosine decay to 5% of base LR
- Replaces the old `StepLR` scheduler
- Implemented via `get_warmup_cosine_lr_scheduler()` in `trainer.py`
