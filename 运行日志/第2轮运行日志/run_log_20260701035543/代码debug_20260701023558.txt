## ✅ Fixes Applied & Status

### Bug Fix 1: `ModuleNotFoundError: No module named 'scgpt'` (Tasks 1-3)
**Root Cause**: `from scgpt.tokenizer.vocab_compat import BuiltinVocab` was placed **before** `sys.path.insert(0, ...)` in all three data scripts. Python resolves imports at module load time, so `scgpt` couldn't be found.

**Files fixed**:
- `data/finetune_perturbation_norman.py` - moved `sys.path.insert` before the scgpt import
- `data/finetune_multiomic_perturbation.py` - same fix
- `data/finetune_integration_optimized.py` - same fix

**Also added**: `export PYTHONPATH="${PROJECT_ROOT}:${PYTHONPATH}"` in `run_log/run.sh` as a global safety net

### Bug Fix 2: `IndexError` in PerturbationEncoder (Task 4)
**Root Cause**: In `scgpt/model/model.py` line 924, `self.pert_scale[x]` used `x` after it was overwritten by `self.embedding(x)` (which converts integer IDs to float embeddings). Float tensors can't be used as indices.

**Fix**: Saved original perturbation IDs (`pert_ids = x`) before the embedding step, then used `self.pert_scale[pert_ids]` for indexing.
