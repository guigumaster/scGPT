**Purpose**: Main training script with prototype-based contrastive learning for cell type-aware fine-tuning.

#### 3. `scgpt/model/model.py` — `PrototypeContrastiveHead` (Modified)

**Improvements to the prototype head**:
- **Normalized initialization**: EMA prototypes initialized with `F.normalize()` for numerical stability
- **Adaptive momentum**: For first 10 updates per class, momentum adapts (0.8 → 0.999) for faster early adaptation
- **Efficient batch update**: Uses one-hot matrix multiplication instead of per-class loop for better GPU utilization
- **Default `use_ema=True`**: Training uses EMA prototypes (stable), not learnable parameters
- **Per-class tracking**: `class_counts` buffer tracks how many samples have been seen per class

#### 4. `scgpt/utils/util.py` — `eval_scib_metrics` (Modified)

**Changes to handle import errors**:

- Both `ImportError` and general `Exception` caught to prevent training crashes

### Root Cause Fix for Previous Failure

The previous run failed with:
```
ImportError: cannot import name 'SparseDataset' from 'anndata._core.sparse_dataset'
```

**Root cause**: `scvi-tools==0.20.3` imports `SparseDataset` from `anndata._core.sparse_dataset`, but this was removed in `anndata>=0.11.0`. The system has `anndata==0.12.17`.

**Fix applied in `run.sh`**:
1. Install scGPT with `pip install -e . --no-deps` to avoid pulling in broken `scvi-tools`
2. Install core dependencies separately with compatible versions
3. The training script does **not** import `scvi-tools` directly — only `scib` (which depends on scvi-tools) is called optionally at the end
4. `eval_scib_metrics` in `util.py` now gracefully handles `scib` import errors

### Data Strategy

The PBMC 3K dataset is split into **3 pseudo-batches** (40%/35%/25%) to simulate multi-batch integration scenarios. This enables meaningful evaluation of both:
- **Cell type separation** (ARI, NMI on cell type labels)
- **Batch correction** (ASW batch, through DSBN and DAR modules)
