## 修改总结

### 核心 Bug 修复

**问题**：`Tutorial_Integration.py` 中 `config.epochs = 60`、`config.lr = 5e-4`、`config.gradient_accumulation_steps = 4` 等赋值操作导致 wandb ConfigError：

```
wandb.sdk.lib.config_util.ConfigError: Attempted to change value of key "epochs" from 15 to 60
```

**原因**：wandb 的 Config 对象在 `wandb.init()` 后默认不允许修改已存在的键值。

**修复**：将 `config.xxx = yyy` 改为 `config.update({"key": value}, allow_val_change=True)`，并合并多个更新到一个 `config.update()` 调用中。

### 修改文件

|--------|--------|
