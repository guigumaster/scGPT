## Summary of Changes

### 🔍 Root Cause Analysis

The CUDA index error (`srcIndex < srcSelectDimSize`) was caused by a **Python argparse bool parsing bug**:

1. `run.sh` passed `--pert_per_gene=False` to the script
2. `argparse` with `type=bool` parsed `"False"` as `True` because `bool("False")` = `True` in Python (any non-empty string is truthy!)
3. This made the `PerturbationConditionEncoder` use `per_gene=True` with **embedding size 3**
4. But `pert_labels` contained **category codes 0-80** (81 perturbation types)
5. **CUDA out-of-bounds**: accessing indices ≥3 in an embedding table of size 3
