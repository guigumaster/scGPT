## Summary of All Changes

### Root Cause Analysis
The original crash was caused by **OOM (Out of Memory)** — the GPU ran out of memory at epoch 3, batch 750/782 due to:
1. `batch_size=32` with `layer_size=256`, `nhead=8` — too large for the GPU
2. `num_workers=4` + `pin_memory=True` causing memory fragmentation
3. `copy.deepcopy(model)` every epoch duplicating GPU memory
4. `prepare_data()` recreating tensors each epoch (memory fragmentation)
5. **MRE metric blowing up** (millions) due to division by near-zero targets, though this was cosmetic

### Files Modified

#### 1. `scgpt/loss.py` — Fixed MRE numerical stability
- **Problem**: `masked_relative_error` divided by `target[mask] + 1e-6`. With binned targets (0-50), values of 0 caused division by 1e-6 → millions
- **Fix**: Only compute on positions where `target > 0.5`, clip max ratio to 1e4, return 0 if no positive targets

#### 2. `scgpt/model/pctaim_model.py` — Memory-optimized masking
- **Problem**: `task_adaptive_mask_value` converted tensors to numpy → CPU round-trip overhead
- **Fix**: Operate directly on torch tensors on the original device, avoiding CPU transfers

#### 3. `data/finetune_perturbation_pctaim.py` — Major memory optimizations
- **Reduced memory**: `batch_size=16` (from default 32), added `num_workers=2` 
- **Enabled gradient checkpointing**: `use_grad_checkpointing=True` for large model
- **Replaced `copy.deepcopy(model)`**: with `state_dict().cpu().clone()` — avoids duplicating GPU memory
- **Pre-computed perturbed_genes_mask_tensor**: avoids creating new tensor each epoch
- **`pin_memory=False`**: for DataLoaders to reduce memory pressure
- **`torch.cuda.empty_cache()`**: between epochs for proper memory cleanup
- **Early deletion**: of intermediate tensors (`data_pt`, loaders) to free memory

#### 4. `data/finetune_integration_pctaim.py` — Same memory optimizations
- **Replaced `copy.deepcopy(model)`** with state_dict copy
- **`pin_memory=False`** for DataLoaders
- **Pre-computed gene_importance tensor** with persistent reference
- **Memory cleanup** between epochs

#### 5. `data/finetune_replogle_pctaim.py` — Same memory optimizations
- **Enabled gradient checkpointing** for large model
- **Replaced `copy.deepcopy(model)`** with state_dict copy
- **`pin_memory=False`** for DataLoaders
- **Pre-computed condition_perturbed tensor** with persistent reference
- **Memory cleanup** between epochs

#### 6. `run_log/run.sh` — Pipeline improvements
- **Reduced perturbation batch_size**: 32→16, increased gradient_accumulation_steps: 1→2
- **Added `--num_workers=2`** to all tasks
- **Reduced replogle epochs**: 15→10
- **Relaxed `set -eo pipefail`** → `set -o pipefail` so one task failure doesn't kill the whole pipeline
- **Added error-resilient pipeline**: each task uses `|| log_error "..." && continue`
- **Better GPU memory config**: `max_split_size_mb:128` added to `PYTORCH_CUDA_ALLOC_CONF`
