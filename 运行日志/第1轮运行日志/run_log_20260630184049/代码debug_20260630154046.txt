## Summary of Fixes

### Bug 1: wandb `ConfigError` when setting `config.load_model = None` (Task 1 & Task 3)

**Root Cause**: After `wandb.init()`, wandb's `config` object freezes all keys. Attempting to change `load_model` from a path string to `None` raised `ConfigError: Attempted to change value of key "load_model"` because the pretrained model path doesn't exist.

**Fix**: Replaced direct mutation of `wandb.config.load_model` with a **local variable** `load_model_path`. The path is checked for existence; if missing, the local variable is set to `None` without touching the frozen wandb config.

**Files modified**:
- `data/finetune_perturbation_norman.py` (Task 1) — 4 changes
- `data/finetune_integration_optimized.py` (Task 3) — 3 changes

### Bug 2: `TypeError: can't convert np.ndarray of type numpy.str_` (Task 2)

**Root Cause**: Cell type labels (e.g., `"T_cell"`, `"B_cell"`, etc.) were string arrays. `torch.from_numpy(train_ct).long()` fails because PyTorch doesn't support string-to-tensor conversion.

**Fix**: Added automatic detection of string dtypes with `np.issubdtype()`. When strings are detected, they're converted to integer codes using `sklearn.preprocessing.LabelEncoder`. Also fixed `celltypes_labels` at the source to use `.cat.codes.values` for integer codes.

**File modified**:
- `data/finetune_multiomic_perturbation.py` (Task 2) — 4 changes
