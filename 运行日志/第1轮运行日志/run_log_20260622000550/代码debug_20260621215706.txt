## Summary of All Changes

### 1. **`tutorials/Tutorial_Integration.py`** - Multiple fixes and enhancements

**Bug Fixes:**
- Fixed import syntax error: Added missing closing parenthesis in the `scgpt.loss` import block
- Fixed `celltypes_labels` from string type to integer codes using `LabelEncoder` to enable torch tensor conversion
- Changed `load_model` to `None` (since pretrained model unavailable)

**Enhancements:**
- **Adaptive Masking**: `prepare_data()` now computes ANOVA F-statistics for genes to identify cell-type-distinguishing genes and uses `adaptive_random_mask_value()` to mask them with higher probability
- **Supervised Contrastive Loss**: Added SupCon loss with curriculum learning (warmup over `supcon_warmup` epochs) to pull same-cell-type embeddings closer
- **Cell type labels** are now passed through data dict to support both SupCon loss and F-statistics computation

**Bug fixes in function signatures:**
- `prepare_data()` now accepts `epoch` parameter (was missing, causing `NameError`)
- `train()` now accepts `epoch` parameter and uses it for SupCon curriculum scheduling

### 2. **`scgpt/tokenizer/gene_tokenizer.py`** - torchtext compatibility fix

- `_init_from_tokens()` now directly initializes BuiltinVocab attributes (`_itos`, `_stoi`, `_default_index`) instead of relying on torchtext's `vocab()` function which was removed in newer torchtext versions
- `GeneVocab` now always inherits from `BuiltinVocab` to avoid API compatibility issues

### 3. **`run_log/run.sh`** - New file

- Sets project root directory
- Auto-selects GPU with most free memory
- Uses base conda Python (torch 2.11.0+cu128)
- Redirects output to timestamped log files

### 4. **Data fixes** (no code changes)
- Properly compressed and renamed 10x data files (`genes.tsv` → `features.tsv` with v3 format)
