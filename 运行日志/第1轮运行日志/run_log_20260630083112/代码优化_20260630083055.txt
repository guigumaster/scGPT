### 三种 PCT-AIM 机制

#### 1. **扰动条件编码器**（`PerturbationConditionEncoder`）
- 将扰动标签（如 guide identity 或条件类型）编码为连续嵌入
- 支持逐基因标志（每个 token 0/1/2）和整体细胞级标签
- 通过可学习缩放系数将扰动嵌入与基因 token 表示相加融合

#### 2. **跨模态交叉注意力层**（`CrossModalFusionLayer`）
- 在 RNA 和蛋白质模态之间建立双向交叉注意力
- 使用门控融合机制（sigmoid 门控）自适应地结合原始表示与交叉注意力更新后的表示
- 完整支持多组学数据（CITE-seq 等）

#### 3. **任务自适应重要性掩码**（`task_adaptive_mask_value`）
- **扰动任务**：对已知的扰动靶基因施加更高的掩码概率（+0.3 提升量，上限 0.9）
- **整合任务**：根据 HVG 状态计算基因重要性分数，在高变异基因上增加掩码率
- **大规模扰动**：在条件特异性基因上使用自适应加权采样，整体掩码率较低（0.35）

### 运行脚本（`run_log/run.sh`）

```bash
# 用法
bash run_log/run.sh                      # 运行完整流水线（所有任务）
bash run_log/run.sh perturbation train   # 仅训练扰动预测模型
bash run_log/run.sh integration eval     # 仅评估整合模型
bash run_log/run.sh replogle test        # 仅测试大规模扰动模型
```

该脚本会：
1. 设置 PYTHONPATH 和 CUDA 环境
2. 检查依赖项（torch、wandb、scib）
3. 依次运行三个任务的训练、评估和测试
4. 为每个任务保存最佳模型检查点
