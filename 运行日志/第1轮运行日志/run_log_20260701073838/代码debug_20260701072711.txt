## Summary of Changes Made

Here's a complete summary of the bugs fixed and code improvements made:

### 1. 🔴 Critical Fix: Gradient Checkpointing `src_key_padding_mask` Bug
**File:** `scgpt/model/pctaim_model.py` (line ~786)

**Root Cause:** In `_encode()`, when `use_grad_checkpointing=True`, `src_key_padding_mask` was passed as a **positional argument** to `self.transformer_encoder`. But `TransformerEncoder.forward(self, src, mask=None, src_key_padding_mask=None)` maps the 2nd positional arg to `mask`, not `src_key_padding_mask`. This caused:
```
RuntimeError: The shape of the 2D attn_mask is torch.Size([8, 1201]), but should be (1201, 1201).
```

**Fix:** Added a wrapper function `_ckpt_forward(x, m, kpm)` that correctly passes `src_key_padding_mask` as a keyword argument to the transformer encoder via gradient checkpointing.

### 2. 🟡 Architecture Override Logic Fix
**File:** `data/finetune_integration_pctaim.py` (line ~202)

**Root Cause:** The condition `config.layer_size != hyperparameter_defaults["layer_size"]` was always `False` because `hyperparameter_defaults` was already updated with `config.layer_size` (both are the same value). So the user's `--layer_size=128` was ignored, and the script always used the pretrained model's `embsize=512`, causing OOM and unnecessary gradient checkpointing.

**Fix:** Changed to check whether the user explicitly passed CLI args (`user_cli_args`), and only fall back to pretrained model config when no CLI override was given.

### 3. 🟡 `ECS` Parameter Name Fix in Trainer
**File:** `scgpt/trainer.py` (lines 259, 526)

**Root Cause:** The trainer used `config.ESC` which doesn't exist in the config (it should be `config.ecs_thres > 0`). This would silently fail to enable ECS loss.

**Fix:** Changed to `ECS=config.ecs_thres > 0 if hasattr(config, 'ecs_thres') else False`.
