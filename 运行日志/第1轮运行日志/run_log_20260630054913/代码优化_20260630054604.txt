## Summary of Changes

### New Files Created

**1. `scgpt/data/__init__.py`**
- Package initializer that exports the Norman data loading functions.

**2. `scgpt/data/norman_loader.py`**
- **`load_norman_data()`**: Multi-strategy loader for Norman Perturb-seq data:
  1. Loads from local `.h5ad` cache if available
  2. Falls back to `pertpy` library (`pt.data.norman()`)
  3. Falls back to `scperturb` library
  4. Downloads raw counts from GEO (GSE133344) as last resort
- **`preprocess_norman_data()`**: Preprocesses Norman data following the same pipeline as PBMC 10K:
  - Gene filtering, normalization, log1p, HVG selection (1200), binning (51 bins)
  - Each perturbation condition (e.g., gene KO) is treated as a **pseudo-batch** for DAR
- **`prepare_norman_continual_pretrain_data()`**: Tokenizes and prepares Norman data for model training

**3. `run_log/run.sh`**
- Complete pipeline execution script with:
  - Automatic GPU selection based on free memory (`nvidia-smi`)
  - Dependency checking (pertpy, scib)
  - Both stages of training orchestration
  - Results collection and summary
  - All paths use absolute paths relative to `PROJECT_ROOT`

- **Separate model instance**: Creates a `TransfomerModel` with `num_batch_labels` matching Norman's perturbation count
- **15-epoch training loop**: Trains with MLM (masked language modeling) + MVC (masked value prediction for cells) + ECS (elastic cell similarity) + DAR (domain adversarial regularization using perturbation conditions as pseudo-batches)
- **Checkpoint saving**: Saves `best_model.pt`, `args.json`, `vocab.json` to `save/scGPT_norman_continual_pretrain/`
- **Weight transfer**: Loads Stage 1 weights into the original model for Stage 2 (using `load_pretrained` with shape-matching, so batch-specific layers are automatically reinitialized for PBMC 10K's batch structure)

### Two-Stage Training Strategy

| Stage | Dataset | Epochs | Loss Functions | Pseudo-Batch | Purpose |
|-------|---------|--------|----------------|--------------|---------|
| **1** | Norman Perturb-seq (K562) | 15 | MLM + MVC + ECS + DAR | Perturbation condition | Teach model to distinguish biological variation from noise |
| **2** | PBMC 10K | 15 | MLM + MVC + ECS + DAR | Original batch labels | Integration fine-tuning with enhanced initialization |
