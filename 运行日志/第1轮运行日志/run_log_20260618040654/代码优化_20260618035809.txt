### 🔬 Key Implementation Details

**1. `PrototypeContrastiveHead`** (in `model.py`):
- Learnable prototype matrix of shape `(n_cls, d_model)` with Xavier init
- `register_buffer` for EMA prototypes (momentum=0.999) — updated after each optimizer step via `@torch.no_grad()`
- Forward pass computes cosine similarity logits with temperature scaling → cross-entropy loss

**2. Curriculum Learning** (in `finetune_integration.py`):
- Cosine ramp-up schedule: `cls_weight` from 0.1 → 1.0, `proto_weight` from 0.05 → 0.5
- Gradual increase over first 15 epochs (configurable via `curriculum_start`/`curriculum_end`)

**3. CCE Contrastive Loss**:
- Existing SimCLR-style dual-encoder contrastive loss enabled with `CCE=True`
- Weight=0.1 (constant throughout training)

**4. Batch Size**:
- Increased from 64 → 256 — leveraging H20's 96GB HBM3

**5. Batch Correction Preserved**:
- DAB (weight=1.0), DSBN, ECS (threshold=0.8), GEPC all kept intact
