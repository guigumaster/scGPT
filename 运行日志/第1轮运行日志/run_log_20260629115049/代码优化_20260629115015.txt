### 3. Nine Key Improvements in `Tutorial_Integration.py`

| # | Improvement | How It Boosts ARI |
|---|------------|-------------------|
| **1** | **Norman Continual Pre-training** - Warms up the model on CRISPR perturbation data (12 epochs with adaptive mask ratio) | Enriches gene-gene interaction understanding, improving cell-type separation |
| **2** | **Contrastive Cell Embedding (CCE)** - `cce_weight=0.05` enables the model's built-in CCE head | Pulls same cell-type embeddings closer, pushes different types apart → directly improves NMI/ARI |
| **3** | **Adaptive Mask Ratio Curriculum** - Starts at 0.65 mask ratio, linearly decays to 0.35 over 30 epochs | Forces model to learn broad gene dependencies first, then refine → better representations |
| **4** | **Cosine Annealing with Warm Restarts** - `CosineAnnealingWarmRestarts(T_0=10, T_mult=2)` | Better convergence than StepLR → lower validation loss |
| **5** | **Extended Training** - 30 epochs (vs 15 baseline) + early stopping on `avg_bio` | More room to converge, stops when metrics plateau |
| **6** | **AdamW Optimizer** - with `weight_decay=0.01` | Better regularization than Adam → generalizes better |
| **7** | **Detailed Metric Tracking** - Logs `ARI_cluster/label`, `NMI_cluster/label`, `ASW_label` separately to WandB | Enables precise monitoring of what improves |
| **8** | **Per-Epoch Adaptive Masking** - `prepare_data()` now takes epoch argument for the curriculum | Smooth transition from exploration to refinement |
| **9** | **Multi-loss Balancing** - MSE + GEPC + ECS + CCE + DAB all properly weighted | Balanced optimization across all objectives |

### 5. Key Architecture

The pipeline follows this flow:
```
Load pretrained scGPT (whole-human)
  → Continual pretrain on Norman perturbation data (12 epochs, adaptive mask)
    → Fine-tune on PBMC 10K (30 epochs, CCE + ECS + DAB + adaptive mask)
      → Evaluate with scIB metrics (ARI, NMI, ASW_label, avg_bio)
```
