## Summary of Changes

### 1. `scgpt/norman_loader.py` - Case-insensitive gene matching
**Problem**: Only 2/1200 Norman genes matched the scGPT vocabulary (case-sensitive)
**Fix**: Added case-insensitive matching in `filter_genes_to_vocab()`. Now matches **952/1200 genes** (up from 2).

### 2. `scgpt/norman_pretrain.py` - Batch labels + autocast fixes
**Problem 1**: `batch_labels=None` passed to model with `use_batch_labels=True` → AssertionError
**Fix**: Always pass `batch_labels` to the model forward call

**Problem 2**: `torch.cuda.amp.autocast` and `torch.cuda.amp.GradScaler` deprecated
**Fix**: Changed to `torch.amp.autocast(device_type='cuda', ...)` and `torch.amp.GradScaler('cuda', ...)`

### 3. `tutorials/Tutorial_Integration.py`
**Problem 1**: Norman preprocessing order (HVG first, then vocab filter) → very few matching genes
**Fix**: Reordered: filter to vocab first (with case-insensitive), then HVG on matching genes

**Problem 2**: Deprecated autocast/GradScaler APIs
**Fix**: Updated to torch.amp equivalents

**Problem 3**: Early stopping based only on avg_bio, not ARI
**Fix**: Added separate tracking for best ARI model, saves `best_model_by_ari.pt`

**Problem 4**: ARI degraded with Norman pre-training
**Fix**: Disabled Norman pre-training (K562 perturbation data hurts PBMC clustering), optimized CCE weight (0.15) and early_stop_patience (10)

### 4. `run_log/run.sh` - Absolute paths
- Changed to use absolute paths for Python and project directories
- Added `PYTHONWARNINGS="ignore"` for cleaner logs
- Uses `PIPESTATUS` correctly for exit code capture
