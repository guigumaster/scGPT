## Summary of Changes Made

### 🐛 Critical Bug Fix

**File: `scgpt/model/pctaim_model.py`** - `task_adaptive_mask_value` function
- **Root cause**: When `gene_importance` or `perturbed_genes_mask` arrays (length = `n_hvg = 1200`) were used, the code was reassigning `gene_prob` with `np.where(...)` or `np.clip(...)`, producing arrays of length 1200 instead of 1201 (which includes the CLS token position). This caused a broadcast error with `rand_vals` of shape `(batch_size, 1201)`.
- **Fix**: All three branches (`perturbation`, `integration`, `large_perturbation`) now:
  1. Initialize `gene_prob` with full `seq_len` (e.g., 1201)
  2. Only update the gene portion `gene_prob[:mask_len]` or `gene_prob[:imp_len]`, preserving the correct shape

### 🚀 Performance Improvements

**File: `scgpt/model/pctaim_model.py`**:
- **Pre-LN support**: Added `norm_first=pre_norm` to `TransformerEncoderLayer` for better training stability
- **Better weight initialization**: Xavier uniform init for `ContinuousValueEncoder` linear layers
- **Stronger perturbation signal**: PerturbationConditionEncoder scale initialized to 1.0 (was 0.5)

**Files: `data/finetune_perturbation_pctaim.py`, `data/finetune_integration_pctaim.py`, `data/finetune_replogle_pctaim.py`**:
- **Fixed deprecated `torch.cuda.amp` API** → Modern `torch.amp.GradScaler('cuda', ...)` and `torch.amp.autocast('cuda', ...)` (PyTorch 2.x)
