```

GPU 0 has a total capacity of 95.08 GiB of which 100.56 MiB is free.
Process 856555 has 80.89 GiB memory in use.
```

运行日志清晰地显示：
1. **Multi-batch Integration (PBMC 10K) 训练任务在执行过程中触发 `torch.OutOfMemoryError`**
