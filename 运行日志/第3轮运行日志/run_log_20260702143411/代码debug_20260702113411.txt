## Summary of Changes

### Problem Analysis
The previous run timed out at 10800 seconds (3 hours) because:
1. **Integration (PBMC 10K)**: 25 epochs × 125s = 3125s
2. **Perturbation (Norman 2019)**: 25 epochs × 290s = 7250s (1559 batches/epoch, 25K cells)
3. **Replogle (2022)**: Only 3/15 epochs completed before timeout
4. **Total**: ~10459s, exceeding 10800s limit

### Changes Made

**1. `data/finetune_integration_pctaim.py`** - Multi-batch Integration
- epochs: 25 → 18 (saves ~875s)
- mask_ratio: 0.4 → 0.35 (faster convergence)
- lr: 5e-5 → 8e-5 (faster convergence)
- weight_decay: 0.05 → 0.03 (better generalization)
- dropout: 0.2 → 0.15 (faster convergence)
- early_stopping_patience: 8 → 6
- data_is_raw: True → False (fixes double log1p warning)

**2. `data/finetune_perturbation_pctaim.py`** - Perturbation Prediction (Norman)
- epochs: 25 → 18 (saves ~2030s - biggest time saver)
- mask_ratio: 0.4 → 0.35
- lr: 5e-5 → 8e-5
- weight_decay: 0.05 → 0.03
- dropout: 0.2 → 0.15
- warmup_epochs: 4 → 3
- early_stopping_patience: 8 → 6
- log1p: True → False (fixes double log1p warning)
- hvg_flavor: "seurat_v3" → "cell_ranger" (fixes warning for preprocessed data)

**3. `data/finetune_replogle_pctaim.py`** - Large-scale Perturbation (Replogle)
