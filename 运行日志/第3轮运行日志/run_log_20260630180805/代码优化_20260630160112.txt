**Hyperparameter Optimization (Stage 2 - PBMC 10K):**
| Parameter | Before | After | Reason |
|---|---|---|---|
| `epochs` | 25 | **15** | Fit within 3h limit |
| `lr` | 2e-4 | **1e-4** | More stable fine-tuning after Norman |

**Performance Optimizations:**
- **`torch.backends.cudnn.benchmark = True`**: Auto-tune cuDNN for input shapes
- **`non_blocking=True`** on all `.to(device)` calls: Overlap CPU→GPU transfer with computation
- **`gc.collect()` + `torch.cuda.empty_cache()`** between every epoch: Prevent memory fragmentation (fixes the 1200ms→2500ms batch slowdown)
- **DataLoader `num_workers=4`**: Parallel data preprocessing in background processes
- **Early stopping** for Norman: Stops when validation loss plateaus for 3 consecutive epochs
- **Explicit `del`** of epoch data structures: Frees memory immediately
