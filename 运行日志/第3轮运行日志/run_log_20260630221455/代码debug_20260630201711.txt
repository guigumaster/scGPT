## Summary of All Changes Made

### 1. Bug Fix: `scgpt/loss.py` - Empty Mask Handling
**Problem:** `masked_relative_error` used `assert mask.any()`, which crashed when the cosine-decayed mask ratio (~0.85% at epoch 18/20) resulted in batches with zero masked positions.

**Fix:** Modified all three loss functions to gracefully return 0 when the mask is empty:
- `masked_mse_loss` - returns `torch.tensor(0.0)` when mask is empty
- `criterion_neg_log_bernoulli` - returns `torch.tensor(0.0)` when mask is empty  
- `masked_relative_error` - returns `torch.tensor(0.0)` when mask is empty (removed `assert`)

### 2. Bug Fix: `tutorials/Tutorial_Integration.py` - Mask Ratio Floor
**Problem:** The cosine mask ratio schedule decayed to near-zero by epoch 18:
```python
mask_ratio_schedule = 0.35 * (1 + cos(π * 18/20)) / 2 ≈ 0.0085 (0.85%)
```

**Fix:** Added a minimum floor of 0.08 (8%) to ensure there are always masked positions:
```python
mask_ratio_schedule = max(
    mask_ratio * (1 + np.cos(np.pi * epoch / config.epochs)) / 2,
    0.08  # minimum mask ratio
)
```
