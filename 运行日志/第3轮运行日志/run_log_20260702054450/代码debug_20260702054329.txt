## Summary of Changes Made

### Bug Fixes

**1. Fixed path bug in `finetune_integration_pctaim.py`** (Critical)
- **Problem**: The evaluation after training tried to load `best_model.pt` **before** it was saved, causing: `[Errno 2] No such file or directory: 'save/dev_PBMC_10K_PCTAIM-Jul02-02-37/best_model.pt'`
- **Fix**: Moved `torch.save(best_model_state, save_dir / "best_model.pt")` to **before** the evaluation block, so the file exists when the evaluation tries to load it.

**2. Fixed relative paths → absolute paths in all 3 training scripts**
- **Problem**: `save_dir` used `Path(f"./save/...")` (relative path), making the code fragile when `cd` is not set correctly.
- **Fix**: Changed to use `Path(_project_root) / f"save/..."` where `_project_root` is obtained from `os.environ.get("PROJECT_ROOT")` or computed from the file location.

**3. Fixed `load_model` relative path in all 3 training scripts**
- **Problem**: `load_model="save/scGPT_human"` was a relative path.
- **Fix**: Changed to `load_model=os.path.join(os.path.dirname(os.path.dirname(__file__)), "save", "scGPT_human")` (absolute path).

**4. Fixed `run.sh` to export `PROJECT_ROOT`** and use absolute paths for `--load_model`

### Model Performance Optimizations

**5. Enhanced `Similarity` module** (in `pctaim_model.py`)
- Changed from raw temperature parameter to **log-space temperature** (`log_temp`) for more stable gradient updates
- Has `temp` property that clamps to `[0.05, 0.5]` to prevent contrastive collapse
- **Impact**: Improves CCE (Contrastive Cell Embedding) convergence → higher ARI/NMI

**6. Enhanced `PerturbationPredictor`** (v5)
- Added **learnable logit scaling** (`logit_scale`) for better multi-label prediction calibration
- Better initialization: final classifier uses `gain=0.1` for stable early training
- Differential dropout: 0.15 in hidden layers, 0.05 in final layer
- **Impact**: Improves perturbation prediction accuracy

**7. Enhanced `EnhancedAdversarialDiscriminator`**
- Added **spectral normalization** on all linear layers for stable adversarial training
- **Impact**: Better batch correction → higher PCR_batch and lower batch effect

**8. Improved `flag_encoder` initialization**
- Clearer separation between expressed (index 1) and non-expressed (index 0) states
- **Impact**: Better expression modeling from the start
