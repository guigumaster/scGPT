## Summary of Changes

### 1. 🔴 Bug Fix: UnboundLocalError (Critical)

**File:** `tutorials/Tutorial_Integration.py`

**Problem:** Variables `norman_train_pt`, `norman_valid_pt`, `norman_train_loader`, `norman_valid_loader` are deleted at the end of each Norman epoch loop iteration (line 1186). When the loop exits (early stopping or all epochs done), these variables are already unbound. The subsequent `del` at line 1225 tried to delete them again, causing `UnboundLocalError`.

**Fix:** Wrapped the second `del` in a `try/except (UnboundLocalError, NameError): pass` block to safely skip already-deleted variables.
