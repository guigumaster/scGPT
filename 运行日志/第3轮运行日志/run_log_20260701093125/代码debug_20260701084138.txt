## Summary of Changes

### Bug Fixed
The original error was a `RuntimeError: Parent directory save/dev_norman_perturbseq-Jul01-07-39 does not exist` when `torch.save()` was called during perturbation prediction training. This happened because:

1. **`finetune_perturbation_norman.py`** ignored the `--output_dir` argument and used a relative path `./save/dev_{dataset_name}-{timestamp}/`
2. The `save_dir.mkdir()` at init created the directory, but on a shared filesystem the directory was not durable across epochs
3. No `mkdir` was called before the actual save operations inside the training loop
