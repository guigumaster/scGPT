## 变更摘要

### 分析的问题（v2 失败原因）

从日志分析看出，v2 的最佳 ARI 为 **0.5563**（scIB 测试为 0.6040），未能达到基线 0.7100。根本原因：

1. **模型太小**：128维 × 3层 × 4头，仅 705K 参数，不足以学习良好的细胞类型表征
2. **批次大小太小**：batch_size=32 导致对比学习梯度噪声大，CCE 损失效果差
3. **CCE 与 Proto 冲突**：两个对比学习目标（CCE + Prototype）存在梯度冲突
4. **课程学习过于激进**：从第0轮开始就注入监督信号，破坏了基因表达重建
5. **CLS权重与重建损失不平衡**：CLS损失(0.2-2.0)远小于MLM+MVC(110+)，监督信号被淹没

### 已修改的文件

**1. `examples/finetune_integration.py`** - 完整重写为 v3 版本，包含12项关键优化：

| 优化项 | v2（旧） | v3（新） |
|--------|---------|---------|
| 模型维度 | 128 | **256** |
| Transformer层数 | 3 | **6** |

| CCE对比损失 | ✅ 启用（与Proto冲突） | **❌ 移除** |
| CLS损失函数 | CrossEntropy | **Focal Loss (gamma=2.0)** |
| 课程学习起止 | epoch 0→15 | **epoch 5→40** |

| 最大Proto权重 | 1.0 | **0.8** |
| EMA动量 | 0.999（固定） | **0.85→0.999（自适应）** |
| HVG基因数 | 1200 | **2000** |
| 训练轮数 | 50 | **80 + 早停** |
| 优化器 | 统一weight_decay | **参数分组优化** |
